# BAS Lock

لوحة شاشة قفل خاصة لأندرويد تعرض:

- الساعة والتاريخ الميلادي والهجري.
- مواقيت الفجر، الشروق، الظهر، العصر، المغرب، العشاء.
- إبراز الصلاة القادمة والعد التنازلي لها، مع عدم اعتبار الشروق صلاة.
- حساب محلي دون إنترنت بطريقة قريبة من أم القرى: فجر 18.5°، عشاء +90 دقيقة بعد المغرب (+120 في رمضان).
- تصحيح يدوي مستقل لكل وقت من −30 إلى +30 دقيقة.
- استخدام موقع الهاتف إن توفر، مع تبوك كقيمة احتياطية.
- قراءة الإشعارات بعد موافقة المستخدم عبر Notification Access، وتصنيفها إلى مهم / مراجعة / أخرى.
- إخفاء نص الإشعار الكامل أثناء قفل الجهاز للحفاظ على الخصوصية.
- الضغط على ملخص الإشعار يفتح التطبيق المصدر عند السماح بذلك.
- محاولة تجريبية للظهور تلقائيًا عند إضاءة شاشة القفل على أجهزة Samsung/Android الحديثة.
- أيقونة BAS Lock الفاخرة مدمجة داخل موارد التطبيق.

## ملاحظة Android

Android الحديث يقيّد تشغيل Activities من الخلفية، لذلك الظهور التلقائي عند إضاءة الشاشة هو **best-effort** وقد يختلف باختلاف إصدار Android وإعدادات البطارية والشركة المصنعة.  
أما `showWhenLocked` فهو مستخدم لعرض BAS Lock فوق شاشة القفل عندما يسمح النظام بتشغيل الـ Activity.

## بناء APK

يوجد GitHub Actions workflow باسم **Build BAS Lock APK**.

1. افتح تبويب **Actions**.
2. اختر **Build BAS Lock APK**.
3. اضغط **Run workflow** إذا لم يكن هناك تشغيل تلقائي ناجح.
4. بعد نجاح البناء افتح التشغيل.
5. من **Artifacts** حمّل **BAS-Lock-debug-apk**.

## أول تشغيل

بعد تثبيت التطبيق:

1. وافق على صلاحية الموقع للحصول على مواقيت مدينتك.
2. اضغط **تفعيل الإشعارات** وامنح BAS Lock صلاحية Notification Access.
3. افتح **الإعدادات** لضبط فروق الدقائق إذا لزم.
4. فعّل أو أوقف **الظهور عند القفل** حسب سلوك جهازك.

- لا يُسمح للبوصلة بعرض قبلة موثوقة عندما يكون الموقع مجهولًا ويستخدم التطبيق تبوك كقيمة احتياطية للصلاة.
- إظهار المدينة أو الإحداثيات المستخدمة وزاوية القبلة من الشمال الحقيقي، وإظهار اتجاه أعلى الهاتف بشكل منفصل.
- زر تحديث الموقع مباشرة في بطاقة القبلة، وتحذير عند حمل الهاتف بصورة شبه عمودية.
- عدم قبول بيانات الموقع المؤقت القديمة جدًا باعتبارها موقعًا حديثًا، مع المحافظة على الإحداثيات المحفوظة حتى تحديثها.
